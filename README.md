# 圖片資料夾

網站目前使用漸層色塊作為圖片預留位置（尚未放入實景照片）。
之後只要把符合檔名的 `.webp` 圖片放進這個資料夾，網站就會自動顯示照片，不需要改任何程式碼。

## 命名規則（對應 assets/data.js 內的 hero 欄位）

- day01-hero.webp／day02-hero.webp／day03-hero.webp／day04-hero.webp
- hotel-nikko-alivila.webp／hotel-jrk-blossom.webp
- naminoue-shrine.webp（波上宮）
- churaumi-aquarium.webp（美麗海水族館）
- sesoko-kayak.webp（瀨底玻璃獨木舟）
- kouri-bridge.webp（古宇利大橋）
- cave-okinawa.webp（CAVE OKINAWA鐘乳石）
- ryukyu-mura.webp（琉球村）
- araha-park.webp（Araha Park安良波公園）
- american-village.webp（美國村）
- kokusai-street.webp（國際通）
- kurazushi.webp／inoh-buffet.webp／yakiniku-kochan.webp／hamanoya.webp／sakihama-noodles.webp／calif-kitchen.webp／makishi-market.webp

建議規格：16:9 或 4:3、寬度 1200px 以上、WebP 格式、檔案 < 300KB（維持載入速度）。
